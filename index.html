Privacy Policy — Trading Strategy Optimizer for TradingView

Last updated: 26 September 2026 (version 2.2.0)

The short version

The extension has no analytics, no tracking, no ads and no account of its own, and it does not sell or share anything about you. The only server it talks to itself is Gumroad's licence service, and only if you enter a Pro licence key. The backtests it runs are run by TradingView, exactly as if you changed your strategy's settings by hand.

What it stores, and where

It keeps things in two places on your own computer.

In TradingView's site storage. The panel runs inside the TradingView chart page, so the few things it remembers about the panel are saved in the browser storage that belongs to tradingview.com:

  • where you left the panel and how big you made it;
  • saved setups (a Pro feature, only when you press Save & Run): for one strategy, the parameter ranges, steps and priorities you chose, plus the metric, search method, filters and number of cycles;
  • a note while a run is going: which strategy it is working on and its name, its settings before the run, the ids of the temporary copies it put on the chart, the address path of the chart layout (such as /chart/AbCd1234/) and when the run started — so that if the browser crashes mid-run, the next load of that chart can offer to clean up. The note is deleted when the run ends normally. If the tab is closed or crashes mid-run it is kept until the next load of that chart has checked it (and you have finished or dismissed the clean-up), and deleted after 30 days in any case. While the run is going, the page also holds a browser lock named after the run, which is how other tabs can tell the run is still alive; the browser releases it when the run ends or the page closes.

Because this is tradingview.com's storage, scripts running on TradingView's pages can read it, as they can anything else on those pages. It holds strategy parameter names and numbers, nothing about you. To erase it, clear the site data for tradingview.com in Chrome (Settings → Privacy and security → Site data). Removing the extension does not clear it.

In the extension's own storage, which websites cannot read:

  • Your licence, if you activate Pro: the licence key, the subscription's status (active, cancelled with the date it ends, ended, refunded, and so on), whether it is monthly or yearly, how many activations Gumroad has counted for the key, and when it was activated and last confirmed.
  • An activation note for each key activated on this browser: a one-way digest of the key (not the key itself) and which activation it was. It is what stops a removed and re-entered key from using up another activation, so it is kept when you press "Remove from this browser".

Removing the extension deletes both. "Remove from this browser" deletes the licence but keeps the activation note.

It does not store your email address, your name, your TradingView username, or any payment details.

What it reads and changes on the chart

On tradingview.com/chart/ pages only, the extension reads the Pine strategy on the chart: its name, its inputs and the Strategy Tester report each backtest produces, plus the chart's symbol and timeframe (shown in the panel and written into exported files). While an optimization runs it writes candidate settings to the strategy's inputs and adds temporary copies of the strategy to the chart so several backtests can run side by side. It removes the copies and puts your original settings back when the run ends.

It does not read other pages or tabs, your browsing history, your TradingView account details, passwords, watchlists, alerts or orders.

Network requests

What TradingView sees. Every backtest is calculated by TradingView under your TradingView account, so TradingView receives each combination of settings that is tried — the same as if you typed them into the strategy's settings yourself. The extension adds nothing to those requests.

Free plan: nothing else. If you never enter a licence key, the extension makes no network requests of its own.

Pro plan: licence checks with Gumroad. The extension sends a request to api.gumroad.com, the licensing service of the store that sells Pro:

  • when you activate a key (a check first, then — only if this browser has not been counted for that key before — a second request that counts the activation);
  • about every 12 hours while Chrome is running, when you press Re-check, at most once an hour when you open the panel, and when a chart page loads and the licence has not been confirmed for over two weeks.

Each request contains your licence key, this extension's product id, and a flag saying whether to count an activation. Nothing else: no chart data, strategies, parameters, results or browsing information. Gumroad's reply describes the purchase (it includes the purchase email address); the extension keeps only the status details listed above and discards the rest. Gumroad's handling of the request is covered by Gumroad's privacy policy.

If a check cannot be made, Pro keeps working for 14 days on the last confirmed answer, then pauses until it can be confirmed again. A cancelled subscription stops at the end of the period that was paid for.

Pressing "Get Pro" opens the purchase page in a new tab. Nothing else is opened or sent.

Files you export

CSV and JSON exports and parameter templates are created in your browser and saved through Chrome's normal download. The extension never uploads them.

Changes

2.2.0 (26 September 2026): the purchase email address is no longer stored or shown to the page; activation notes were added; a run now keeps a short recovery note in tradingview.com's site storage (kept after a crash until the chart has been checked, 30 days at most); this policy now also describes the tradingview.com site storage and what TradingView receives during backtests. An earlier version of this policy mentioned a random installation id; the extension never created one.

Future changes will be published here with a new date, and any change to what data is handled will be called out in the release notes.
